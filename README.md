# 六人兩隊手機拉霸遊戲

## 功能
- 最多 6 位玩家、藍隊與紅隊各自累積分數。
- 每位玩家每局 3 次拉霸，六人到齊後才能開始。
- 三個相同符號 50 分；三個 7️⃣ 為 100 分；任兩個相同 10 分；其他 0 分。
- 各手機即時同步隊伍分數、玩家次數與拉霸紀錄。

## 本機執行
需要 Node.js 18 或更新版本。
```bash
npm install
npm start
```
開啟 http://localhost:3000。若要用同一 Wi-Fi 的手機測試，請在手機瀏覽器開啟 `http://電腦的區域網路IP:3000`。

## GitHub 與 Render 部署（新手）
1. 登入 GitHub，建立新 repository，名稱可用 `party-slot-6-player`。
2. 解壓縮本專案，把資料夾內所有檔案（包含 `public` 資料夾）上傳至 repository 根目錄。
3. 登入 Render，選 **New + → Blueprint**，連結剛才的 GitHub repository。
4. Render 讀取 `render.yaml` 後，確認建立服務並等待部署完成。
5. 開啟 Render 提供的 `https://....onrender.com` 網址。
6. 第一位玩家輸入暱稱、選隊伍並按「建立新房間」；把網址和六碼房間碼傳給另外五人。
7. 其餘玩家打開同一網址，輸入暱稱、選隊伍、輸入房間碼後按「加入房間」。六位玩家到齊後即可各自拉霸。

## 注意事項
- Render 免費方案可能休眠，第一次開啟可能要等服務喚醒。
- 房間資料目前存放在伺服器記憶體中；伺服器重啟或重新部署後，房間和分數可能消失。
- 斷線玩家的名額會保留，避免本局被其他玩家取代；目前斷線後若要繼續，建議重新整理前先確認是否仍保留連線，否則可開新房間重玩。
- 目前任何玩家都能按「重新開始本局」，正式活動若需要可再加上主持人權限。
